Dúvidas

Perguntas frequentes

Preciso criar uma conta? +

Não. Zero cadastro. O Dozr funciona completamente offline — seus dados ficam no iPhone e nunca saem dele.

Funciona para medicamentos prescritos? +

Para qualquer coisa que você precisa tomar regularmente: remédios, vitaminas, suplementos ou fitoterápicos. O Dozr não é um aplicativo médico — é uma ferramenta de organização e hábito.

Quantos suplementos posso adicionar gratuitamente? +

No plano gratuito você pode adicionar até 5 itens — suficiente para a maioria das rotinas. Para rotinas mais completas, o plano Pro oferece itens ilimitados.

Meus dados ficam seguros? +

100%. Nenhum dado sai do seu dispositivo. Sem nuvem, sem conta, sem empresa acessando seu histórico. Seus hábitos de saúde são privados.

Como cancelo o Pro? +

Pelo próprio iPhone: Ajustes → [seu nome] → Assinaturas → Dozr Pro. Cancele a qualquer momento, sem burocracia. A assinatura fica ativa até o fim do período pago.
